Three directions for the browser chrome

Each direction is rendered in light and dark with the tab strip below the address bar. The active tab is drawn in the page's own color so it reads as part of the page. Hover tabs, click an address field to see the focus ring, and try the first-run screen at the bottom.

A · Folio

Recommended

The active tab is cut like a folder tab, with curved shoulders that flow into the page. Inactive tabs have no background, only hairline dividers, so the strip stays quiet. The chrome is cool stone grey, the page area is the brightest surface on screen, and the accent is a deep teal.

Palette

Light
Dark

Type

Instrument Sans for the whole chrome. Slightly narrow, so long tab titles fit, with an open, modern feel. The hostname is semibold and the rest of the URL is muted.

Shape

10px radii. The only shaped element is the active tab. Toolbar 48px plus tab strip 40px, 88px of chrome in total.

B · Graphite

A dense, precise direction for people who live in their browser. Tabs are equal-width cells in a recessed track. The active cell is filled with the page color and drops the divider below it. Each tab shows its Alt+number shortcut, URLs are set in monospace, and the accent is cobalt.

Palette

Light
Dark

Type

Atkinson Hyperlegible, designed for low-vision readers, so similar letterforms stay distinct. JetBrains Mono for URLs, where spotting a lookalike domain matters.

Shape

5–6px radii, square cells, hairline borders. 42px toolbar plus 32px strip, 74px of chrome in total.

C · Pebble

Soft and tactile. The page sits as an inset card on a warm grey backdrop. Controls are round, tabs are pills, and the active pill grows a stem down into the card. Of the three it is the friendliest and most consumer-facing. The accent is a muted berry.

Palette

Light
Dark

Type

Figtree, a geometric sans with round dots and generous counters that suits the pebble shapes. Semibold is reserved for the active tab.

Shape

Full pills, circular buttons, and a 14px card radius. 52px toolbar, 40px strip, and an 8px card margin: the most chrome of the three.

Indicators in Folio

Anything about the current page lives in the address field, which always describes the active tab. The tab strip carries only per-tab state that you need to see across tabs: loading, sound, and camera or microphone in use. HTTPS is the normal case, so it gets no badge. Only exceptions get a label.

First run in Folio

Standard is selected, so pressing Continue keeps it. Technical options stay collapsed under Advanced. Choosing a card or flipping a toggle updates the other, so the cards always match the toggles.

Why Folio

  • Putting tabs below the address bar puts them right next to the page, so a folder tab connects the two literally. The other directions need a stem (Pebble) or a missing divider (Graphite) to make the same point.
  • It wastes no pixels. Pebble's inset card costs about 8px on three sides of every page, which adds up on a 13-inch laptop.
  • It is neutral enough to sit inside your desktop without fighting it, and the folder tab is distinctive enough that nobody mistakes it for a stock browser.
  • Graphite's best ideas carry over: Alt+number hints on hover and the semibold-host URL treatment. Pebble's softness could come back later as a separate "comfortable" density.
